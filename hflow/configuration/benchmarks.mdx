title: "Benchmarks"
description: "Adjust reading accuracy and fluency benchmark targets when your school exposes this tool."
---

Some organizations surface a **Benchmarks** item under **Configuration** (or within the **Languages** workspace) so administrators can tune the benchmark lines overlaid on reading charts. Defaults work for many schools—only change targets when instructional leadership aligns on new goals.

## If you see Benchmarks under Configuration

1. Open **Configuration** → **Benchmarks** when the link appears in your menu (not every deployment shows it yet).
2. Select **school year**, **period** (BOY / MOY / EOY), and **grade**.
3. Enter **target accuracy** and **target fluency** values prescribed by your team.
4. Save.

Reading charts then use those targets as their reference overlays.

If **Benchmarks** is missing, continue using charts with built-in defaults. Many schools consolidate benchmark editing inside **Languages**; see [Languages](/hflow/languages).
