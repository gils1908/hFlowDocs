This feature allows **admins and owners** to create classes and assign students for a school year and grade from **Students → Classes**. Teachers do not see this screen.

Use **[Student enrollment](/hflow/students/student-enrollment)** when you need to advance students into a **future** school year. Use Classes when you need to move students between classes (or Unassigned) in the year you are viewing.

> **Demo data notice**
> Any names, student records, IDs, and examples shown in this documentation section are fictitious sample data for demonstration and training purposes only. Any resemblance to real persons, schools, or records is purely coincidental.

## Before you start

1. Go to **Students → Classes**.
2. Choose **School year** and **Grade**. The board shows Unassigned plus each class for that grade.
3. Optionally use **Search** to find students by name or student code. Matching students stay visible, are highlighted, and are selected. Other students are hidden. Class columns stay available so you can drop or move matches into a class.
4. Use **Clear All** to reset year, grade, and search.

## How to move students

1. Drag a student into another class column or into **Unassigned**.
2. Or select several students (checkbox, or Command/Ctrl/Shift-click a row), then use the bottom bar **Move to…** list.
3. After a move, a short confirmation appears.

Double-click a student name to open that student’s profile.

A small colored dot on a student row shows their most recent reading tier when one is available. If there is no displayable tier, no dot appears.

## How to add or rename a class

Classes belong to the **school year** you are viewing. Classes from another year do not appear here. Within a school year, class names must be unique across your school (not only within the grade). Matching is case-insensitive. The same name may be used again in a different school year.

1. Click **+ Add class**, type a name, then press Enter or click away to save.
2. If that name is already used for this school year, the draft stays open with a short message under the field. Edit the name and save again.
3. Click a class name to rename it inline. **Unassigned** cannot be renamed or deleted.

## How to delete a class

1. Move every student out of the class first (including students who are hidden by search).
2. Click the trash control on the class column.
3. Confirm delete in the prompt.

If the class still has students, you see a message to move them out first. Deletion is blocked until the class is empty.

## How to add a student from a column

1. Click **+ Add student** at the bottom of a class column (or Unassigned).
2. Enter the student’s name (and optional external ID).
3. School year, grade, and class are already set from the board and cannot be changed in the modal.

After you save, the student appears in that column for the selected year and grade.
