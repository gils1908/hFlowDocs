This feature allows admins to enroll selected students into a school year and class from **Students → Enrollment**. Use it to advance students to a later school year, or to reassign class in the current year.

> **Demo data notice**
> Any names, student records, IDs, and examples shown in this documentation section are fictitious sample data for demonstration and training purposes only. Any resemblance to real persons, schools, or records is purely coincidental.

## How Bulk Enroll works

Each **Bulk Enroll** run applies **one target school year** and **one target class** to every student you selected.

- Select everyone who should land in the **same** target year and class, then run Bulk Enroll once.
- To place students into different classes (for example some into `3a` and some into `3b`), run Bulk Enroll once per target class.
- Source class does not have to match. Students can come from different current classes as long as they share the filters below.

If the target grade has no class sections yet, you can enroll without a class (or create a section in the modal when the product allows it).

## Before you start

1. Go to **Students → Enrollment**.
2. Set **Current year** to the school year you are working from (for example `2024-2025`).
3. Choose **exactly one grade**. Bulk Enroll stays disabled until a single grade is selected.
4. Optionally narrow **Class**. **All classes** is fine when you are remixing across sections.

## How to run Bulk Enroll

1. On **Enrollment**, select the students who should share the same target year and class.
2. Click **Bulk Enroll**.
3. Choose the **target school year**:
   - A **later year** creates a new enrollment for the next grade path (for example grade 2 in `2024-2025` advancing into `2025-2026`).
   - The **same year** updates class for students who are already in that year (reassignment).
4. Choose the **target class** when the target grade has sections. Create a new section in the modal when you need one and the product offers that option.
5. Click **Next**, review the summary (including any students who will be skipped), then **Confirm**.

After you confirm, the roster updates for those students. Anyone already enrolled in the target school year is skipped and listed in the review step.

You can also open a single student from the row actions to manage that student’s enrollment years one at a time.

## Examples

### Advance one class together

You want every student in grade 2 class `2a` for `2024-2025` to move into `2025-2026` class `3a`.

1. Set **Current year** to `2024-2025`, **Grade** to `2`, **Class** to `2a`.
2. Select all listed students.
3. **Bulk Enroll** → target year `2025-2026` → class `3a` → confirm.

### Remix students from two classes into two new classes

You want a mixed group from `2a` and `2b` to become `3a`, and the remaining students to become `3b`.

1. Set **Current year** and **Grade** (for example grade 2). Leave **Class** as **All classes**.
2. Select every student who should go to `3a` (from both `2a` and `2b`).
3. **Bulk Enroll** → target year `2025-2026` → class `3a` → confirm.
4. Clear the selection, then select everyone who should go to `3b`.
5. **Bulk Enroll** again → same target year → class `3b` → confirm.

### Reassign class in the same school year

Some grade 4 students in `2024-2025` should move from `4a` into `4b` without changing school year.

1. Filter to that year and grade, then select those students.
2. **Bulk Enroll** → target year **`2024-2025`** (same year) → class `4b` → confirm.

Their grade and school year stay the same; only class changes.

### Fix students missing a class after CSV import

A CSV left some grade 4 students in `2024-2025` without a class, and the grade already has sections.

1. On **Enrollment**, filter to that year and grade. Find students with no class (for example leave **Class** as **All classes** and scan the **Class** column).
2. Select those students.
3. **Bulk Enroll** → target year the **same** year → choose the correct class → confirm.

When the target grade has sections, a class is required.

## Bulk Enroll vs CSV

| Use Bulk Enroll when… | Use CSV when… |
|---|---|
| You are choosing students interactively on **Enrollment** | You need many different target classes in one file |
| You are advancing or reassigning a selected group to **one** target class | You are importing or updating large batches at once |

To add new students or update many rows at once, see [Add students (manual + CSV)](/hflow/students/add-students). For undo of a CSV upload, see [CSV imports and undo](/hflow/configuration/csv-imports).

## Common issues

- **Bulk Enroll is disabled:** Select exactly one **Grade**, then select at least one student.
- **Some students were skipped:** They already have an enrollment for the target school year. Review them individually or pick a different target year.
- **A class is required:** The target grade already has sections. Choose or create a class before confirming.
- **Wrong students in the list:** Check **Current year**, **Grade**, and **Class** filters. Changing filters clears the current selection.
