This page explains how **Students** behaves for **owners**, **admins**, and **teachers**. For how roles are assigned and who can open **Staff**, see [Staff roles and permissions](/hflow/configuration/staff).

## Most common use case

When you are troubleshooting “why can’t I see this button/student?” start with this page first.

## Owner and admin visibility and actions

**Owners** and **admins** (sometimes called “admin mode” in the app) can:

- See all active students in the organization (subject to filters)
- Use full filters (year, language, grade, class, reading tier, search). Grade, class, and reading tier each support multiple selections (OR logic). Language stays a single selection on this page.
- Add students manually
- Import students from CSV
- Export students to CSV
- Open the student data drawer
- Edit student name details from the row action
- Open Student Enrollment and remove a student from roster

Only **owners** manage staff invitations and roles under **Configuration → Staff**.

## Teacher visibility and actions

Teachers see only students within the union of active assignments (year + grade + optional class match).

Teacher behavior:

- Assignment-focused header (select one or more assignment rows; roster is the union of matches)
- Search within assigned roster
- No Add Student, Import CSV, Export CSV, or edit-row actions
- Drawer access depends on assessment permissions:
  - If assessment access is enabled: student name opens drawer
  - If disabled: names are read-only text and drawer is not available
- Notes are view-only in the drawer for teachers

## Role troubleshooting checklist

### 1) Teacher cannot see expected students

Check:

- Teacher has active assignment(s) for the current date
- Assignment school year and grade match student-year records
- If assignment class is set, class name must match

### 2) Teacher cannot open drawer

Check:

- Teacher has assessment access enabled on their staff record (an **owner** sets this under **Configuration → Staff**)

### 3) “Missing” admin actions

Check:

- Current user role is **owner** or **admin** (not **teacher**)

<Note>
  Teachers see assignment pickers and search without import, export, or add-student actions—the layout is narrower than this admin example.
</Note>
