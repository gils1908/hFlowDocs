This section covers **Reports** from the header: cohort views for reading tiers, reading growth, pooled language progress, and grade-wide language distributions. Individual student trends are documented under [Student progress charts](/hflow/students/student-progress-charts).

## How to open any report

1. In the app header, hover **Reports**.
2. Pick the report you need (names match the app menu).

Each report opens its own filters (when relevant) followed by charts on the workspace below. Use the **Shortcut** control to apply the same saved filter view you use on **Students** or **Assessments**. See [Shortcuts](/hflow/shortcuts).

## Organization reports

- [Reading tier distribution](/hflow/reports/reading-tier-distribution): tier mix by BOY / MOY / EOY (no Copy Charts).
- [Growth report (reading)](/hflow/reports/growth-reading): reading growth visuals; includes **Copy Charts**.
- [Language progress report](/hflow/reports/language-progress-report): pooled language metrics; includes **Copy Charts**.
- [Grade language level distribution](/hflow/reports/grade-language-distribution): dual-panel ACTFL and comprehension view; wide **Copy Charts** PNG.

## Copy Charts behavior

**Copy Charts** appears on **Growth Report - Reading**, **Language Progress Report**, **Grade Language Distribution**, and on the [student progress charts](/hflow/students/student-progress-charts) page for an individual learner.

Browsers that support clipboard images show **Copied to clipboard!** briefly; otherwise hFlow downloads a PNG and flashes the same confirmation text so you know the file saved locally.

During capture the button shows **Capturing…** and is temporarily disabled.

### Common errors

- **Couldn't capture charts:** Try again after the charts finish loading, or use a screenshot if the browser blocks image export.
