This report shows **ACTFL** and **comprehension / level** distributions together for the cohort you select. It helps leaders compare skill spread and reading comprehension levels under the same filters.

## How to open this report

1. In the app header, open **Reports**.
2. Choose **Grade Language Distribution** (wording on the menu matches the app).

## How to use the report

1. Choose **language**, **school year**, optional **grades** and **classes**, and the **skill** (Reading, Listening, Speech, Writing, or Overall).
2. Review the two chart panels; both use the same filters and periods.
3. Use **Copy Charts** to capture **both** panels in one wide PNG. The control stays disabled when there is no assessed data for the current selection.

For **Copy Charts** details, see the [Reports hub](/hflow/reports).
